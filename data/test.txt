Язык программирования Lua

Lua — это лёгкий, встраиваемый скриптовый язык программирования. 
Он был разработан в 1993 году в Католическом университете Рио-де-Жанейро 
(Бразилия) группой Roberto Ierusalimschy, Waldemar Celes и Luiz Henrique de Figueiredo.

Переменные в Lua

В Lua переменные могут быть глобальными и локальными. 
По умолчанию все переменные являются глобальными. 
Для создания локальной переменной используется ключевое слово local.

Пример объявления локальной переменной:
local x = 10
local name = "Lua"
local table = {1, 2, 3}

Область видимости локальной переменной начинается сразу после её объявления 
и продолжается до конца блока, в котором она объявлена. 
Блок — это тело функции, управляющая конструкция или chunk (файл/строка).

Рекомендуется всегда использовать local для объявления переменных. 
Глобальные переменные засоряют глобальное окружение и могут создавать 
конфликты имён между модулями. Кроме того, доступ к локальным переменным 
быстрее, чем к глобальным, потому что они реализованы как стековые 
переменные виртуальной машины Lua.

Типы данных в Lua

Lua — динамически типизированный язык. Переменные не имеют типов, 
типы имеют только значения. Основные типы:

1. nil — отсутствие значения
2. boolean — логический тип (true/false)
3. number — числовой тип (целые и с плавающей точкой)
4. string — строки
5. table — таблицы (ассоциативные массивы)
6. function — функции как значения первого класса
7. userdata — пользовательские данные из C
8. thread — корутины

Таблицы в Lua

Таблицы — единственная структура данных в Lua. 
Они реализуют ассоциативные массивы и могут использоваться как:
- Обычные массивы (с числовыми индексами)
- Записи/структуры (с строковыми ключами)
- Объекты (с метатаблицами)
- Модули и пакеты

Пример создания таблицы:
local person = {
    name = "John",
    age = 30,
    hobbies = {"reading", "coding", "gaming"}
}

Функции в Lua

Функции в Lua — это значения первого класса. 
Они могут храниться в переменных, передаваться как аргументы 
и возвращаться из других функций.

Пример:
local function greet(name)
    return "Hello, " .. name .. "!"
end

print(greet("World"))  -- Hello, World!

Функции могут быть анонимными:
local add = function(a, b) return a + b end

Корутины

Lua поддерживает симметричные корутины через библиотеку coroutine. 
Корутины позволяют приостанавливать и возобновлять выполнение функций, 
что полезно для реализации генераторов, многозадачности и асинхронного кода.

local co = coroutine.create(function()
    for i = 1, 5 do
        print(i)
        coroutine.yield()
    end
end)

coroutine.resume(co)  -- 1
coroutine.resume(co)  -- 2

Метаданные и метатаблицы

Метатаблицы позволяют переопределять поведение операций над таблицами. 
Через метаметоды можно реализовать:
- Перегрузку операторов
- Защиту от модификации
- Наследование
- Автоматическую инициализацию полей

local mt = {
    __tostring = function(t)
        return "Point(" .. t.x .. ", " .. t.y .. ")"
    end,
    __add = function(a, b)
        return {x = a.x + b.x, y = a.y + b.y}
    end
}

Заключение

Lua — мощный и элегантный язык с минималистичным дизайном. 
Его простота и встраиваемость сделали его популярным в игровой индустрии 
(World of Warcraft, Roblox, Defold), конфигурации (nginx, Wireshark) 
и встраиваемых системах.
